Give the shop more than one page

Backspin Records is on screen and it has exactly one page: a list of records, no nav, nowhere else to go. Tonight you give it a few more rooms and a way to walk between them without blowing the whole place up.

1. Run it

npm install
npm run dev

Open http://localhost:3000. Six records, a header, a line that says App started at …. Refresh the page and watch that time change — that's your proof the app just restarted from nothing. Keep an eye on it tonight; it's the only instrument you have for "did I just destroy the app or not."

2. Read before you touch anything

app/page.tsx is a plain list, no links. components/Header.tsx has the clock and a comment: // No nav yet. That comment is your job for tonight.

AI hint — before you write a line of code. If "the app restarted" versus "the page changed" still feels fuzzy, ask:

"In a Next.js app, what's the difference between the browser loading a brand new document and a client-side navigation? What actually gets thrown away in each case?"

Read the answer, close the chat, come back. You should be able to explain it to someone else by the end of tonight, not just have it open in a tab.

3. Make a page

Required. There is no list of routes anywhere in this project — the app/ folder is the routing table. A folder with a page.tsx in it is a page, and the folder's name is the address.

Make app/about/page.tsx:

export default function AboutPage() {
  return (
    <main>
      <h2>About Backspin</h2>
      <p>We buy, sell, and argue about records since 2011.</p>
    </main>
  );
}

Save it, visit /about in the browser. It exists. You never registered it anywhere.

4. Nest a section, and wrap it

Required. Folders nest and the address nests with them. Build a small Help Center with two pages under one shared wrapper:

  • app/help/layout.tsx — wraps everything under /help. Give it a small heading or breadcrumb, then render {children}.
  • app/help/shipping/page.tsx — answers /help/shipping.
  • app/help/returns/page.tsx — answers /help/returns.

Visit both addresses. Both should show your Help Center wrapper around different content. The root app/layout.tsx (where the Header lives) wraps everything; your new help/layout.tsx wraps only the two pages under it.

Stop and check. Visit / — the Help Center wrapper should not appear there. If it does, the layout file is in the wrong folder.

5. Build the nav — and break it on purpose first

Required. In components/Header.tsx, replace the // No nav yet. comment with a real nav, using plain HTML anchors to start:

<nav>
  <a href="/">Catalog</a>
  <a href="/about">About</a>
  <a href="/help/shipping">Help</a>
</nav>

Note the time in App started at …. Click About, then click back to Catalog. The time changed. A plain <a> asks the browser for a whole new document and throws the running app away — every variable, all of it — and starts over.

Now swap every <a> for <Link>:

import Link from "next/link";

<nav>
  <Link href="/">Catalog</Link>
  <Link href="/about">About</Link>
  <Link href="/help/shipping">Help</Link>
</nav>

Click the same trip again. The clock holds still. Same navigation, same pages swapping on screen — the difference is entirely in whether the app underneath survives the trip.

Expect this one. Header already says "use client"; at the top for the clock. That's why hooks and interactivity are allowed there at all — a plain <a> or <Link> doesn't actually need it, but the clock does.

6. Optional, if you finish early

  • Add a fourth page, app/help/faq/page.tsx, then visit /help/nonsense — that's Next's default 404. Add your own app/not-found.tsx to replace it with something on-brand.
  • Give the Help Center layout a small nav of its own, so /help/shipping and /help/returns can be reached without going back through the header.
  • Style the current page's nav link differently (hint: a layout or page can check usePathname() from next/navigation).

AI hint — going deeper. Once it all works, ask:

"Why does a layout.tsx file only wrap the pages inside its own folder, and not pages elsewhere in the app? What decides that?"

That's the exact question lab 2 depends on the answer to.

What "done" looks like

  • /about, /help/shipping, and /help/returns all exist and show something.
  • The Help Center wrapper appears on both help pages and nowhere else.
  • The header has a working nav using <Link>, and the clock never changes while you click around the site.
