What to make this page do

Five things on a menu, each with an Add button that currently does nothing. An empty order list. A total that says 0.00 and never changes. Your job is to wire it up.

The HTML and CSS are finished. script.js is already connected at the bottom of this page, and it is empty.

First, prove the connection. Put console.log('connected'); in script.js, reload this page, and open the console (right-click → Inspect → Console). If you don't see the word connected, stop and fix that before writing anything else.

Action 1 — Required

Clicking Add next to the latte makes the word Latte appear in the empty order box. One item, one button. Get that working before you touch the other four.

Action 2 — Required

Clicking it again adds a second line — the first one stays. Two lattes means two lines in the box. If your second click replaces the first line instead of joining it, that's the right bug to be looking at.

Action 3 — Required

The total keeps up. Every time something is added, the number next to Total goes up by the price of that item.

Read the price off the page — don't type the number into your JavaScript. Every price on this menu has its own id (price-latte, price-drip, and so on), and every total is sitting in total. Take what's there, add to it, put it back.

Action 4 — Optional

Wire up the other four buttons, then Start over — it empties the order box and puts the total back to 0.00.

Action 5 — Optional, and expect this one to fight you

Every line in the order gets its own Remove button, and it removes that line. Not the last one, not all of them — the one you clicked. Take its price back off the total while you're at it.

Give the button you build class="remove" and the stylesheet will make it look right and sit on the correct side of the row. You don't have to style anything.

The part that makes this hard is that the button doesn't exist yet when the page loads. You are building it in JavaScript and then telling that button what to do, which is a different shape from everything above. Roughly: 

var line   = document.createElement('li');
var button = document.createElement('button');
button.className = 'remove';
button.textContent = 'Remove';

button.addEventListener('click', function () {
  line.remove();        // takes this one line off the page
  // and here: put the price back
});

line.textContent = 'Latte';
line.appendChild(button);
document.getElementById('order').appendChild(line);

Type it, don't paste it. Then change one thing and see what breaks — that's how you find out which line was doing what.

If your older Remove buttons quietly stop working, that's the real lesson here. Adding a row by gluing text onto innerHTML throws away every line in the box and builds them all again from scratch. The new rows look identical, but the buttons on them are not the buttons you attached anything to — those are gone. Building rows with createElement and appendChild, like above, leaves the existing ones alone. Log this one; it's a bug you cannot see by looking at the page.

And if Remove keeps the total honest while Add is still producing something strange, that is a clue rather than a coincidence. Write down that the two behave differently, even if you can't say why yet. You'll be able to next week.
